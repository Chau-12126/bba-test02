### **1. Playwright là gì?**
- Là một framework, ưu điểm tương thích với nhiều trình duyệt như firefox, chrome, edge,..
Tính năng xịn xò, dễ cài đặt, cú pháp đơn giản

#### **1.1 Các công cụ cần thiết khi học Playwright**
- NVM = Node Version Manager, quản lý các phiên bản NodeJS (công cụ để chạy code)
Git, Github, VSCode

### **2. Cách để khởi tạo Playwright với một project mới hoàn toàn**
- Chọn mở vào folder vừa tạo ví dụ pw-course >> Chuột phải chọn **Open git bash here**
- Vào git gõ câu lệnh npm init playwright@latest >> TypeScript >> Enter >> ko add gitHub work flow
- Mở folder pw-course từ VSCode
- Tạo mới 'new repository' trên Github, copy đường link SSH. Vào thư mục pw-course trên VSCode mở Terminal nhập lệnh `git remote add origin (link SSH vừa copy)
-  Thực hiện lệnh `git config user.name "Chau"`
